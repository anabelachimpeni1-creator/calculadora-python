Calculadora em Python

Descrição
Este projeto consiste numa calculadora desenvolvida em Python para realizar operações matemáticas básicas.

 Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão
- Validação de divisão por zero

 Tecnologias

- Python 3

 Objetivo
Este projeto foi desenvolvido para praticar:
- Funções
- Estruturas condicionais
- Entrada e saída de dados
- Organização de código

  Próximas melhorias
- Interface gráfica
- Histórico de operações
- Menu interativo
- Tratamento avançado de erros
